# HD MOTORS 设计工具箱

围绕粒子电机展开的沉浸式设计工具箱。没有传统边栏和工具卡片，五项功能以空间标注融入场景。直接用浏览器打开 `index.html` 即可使用；本地预览可运行：

```sh
npm start
```

在项目目录运行，无需安装依赖。访问 http://127.0.0.1:4318 。也可运行 `node serve.mjs`；macOS 可双击 `启动设计工具箱.command`。

## 当前功能

- 全屏电机粒子场：定子、绕组、转子、转轴与磁力流线，青蓝紫配色并以暖铜色区分绕组。
- 场景交互：鼠标移动引起局部粒子扰动；在背景空白处点击激发涟漪；在电机区域拖动旋转；“解构电机”展开结构，“复位视角”恢复视角。该画面为概念可视化，不用于电磁仿真。
- 运动控制：可暂停背景，支持系统减少动态效果偏好、隐藏页面暂停与移动端降采样。
- 场景入口：点击电机周围的文字标注进入工具；悬停或键盘聚焦时对应部件亮起，细引线随电机转动。
- 工具索引：右上角入口、⌘K / Ctrl+K 或 / 打开；支持搜索、收藏、最近使用、方向键选择和 Enter 打开。收藏与最近使用仅保存在本机浏览器。
- 计算浮层：轻量半透明界面，关闭后回到完整场景。
- 铸件重量：按净体积、可编辑密度与数量计算。
- 转子惯量：均匀实心 / 空心圆柱绕中心轴的转动惯量。
- 线规分重：输入两种裸铜线直径、各自根数与铜线总净重量，按「直径² × 根数」分配重量，同时显示两种规格的重量和占比。前提为所有铜线单根长度相同、铜密度相同；不含漆膜、绝缘或包装重量。例如 Ø1 mm × 2 根与 Ø2 mm × 1 根，共 12 kg，分别分配 4 kg 与 8 kg。
- 电阻换算：输入单相绕组直流电阻，默认从测量温度 75 °C 折算到目标温度 20 °C，同时输出目标温度下的相电阻、三角接法线电阻（2/3 倍相电阻）和星型接法线电阻（2 倍相电阻）。按三相绕组电阻相等、第三线端悬空的线间直流测量模型计算；铜 / 铝材料常数与温度范围在工具内注明。
- 能效查询：接入 [ka33u/motor-efficiency-](https://github.com/ka33u/motor-efficiency-) 项目的 GB/T 30253—2024 变频控制同步电机一级能效参考查询。输入转速与功率，显示一位小数的参考效率、查表/插值/外推方式和参考区间；支持重置、输入校验和结果复制。
- 待开发：单位换算、绕组参数计算、公差配合查询。

五项工具支持输入校验、重置和结果复制。复制需要浏览器剪贴板权限；不可用时可手动选择结果文字。

能效数据固定来自上述项目提交 `9799465e8aab001662d85d0b280802220057ab2e` 的 `utils/data.js` 和 `utils/interpolation.js`，共 28 行 × 14 列，保留原项目的匹配边界、0.001 容差和取整行为。输入范围为有限数 `0 < 转速 ≤ 6000 r/min`、`0.55 ≤ 功率 ≤ 1250 kW`；315–1250 kW 使用同一行。低于 45 r/min 时沿用源项目基于 45、60 两列的外推，并明确标注，不称为标准表内值。

源项目注释记录 1.1 kW、45 r/min 原表显示 69.9%，项目作者按趋势采用 59.9%。工具沿用 59.9%，页面不展示该修正说明，来源记录保留在本文及数据文件中。这是项目修订，不是已核验的标准勘误；全部能效表尚未独立核对官方原文，因此界面使用“项目表值 / 参考效率”，不作实测效率或等级认证判定。

接法模型参考：[maxon《maxon EC motor》培训资料第 13 页](https://www.maxongroup.com/medias/sys_master/8803451338782.pdf?mime=application/pdf&realname=maxonECmotor_Notes.pdf)，其中说明同一组三相等电阻绕组改接时，星型端电阻为三角接法的 3 倍。具体线间值按串并联电路计算。

所有页面样式、计算、能效表与粒子均本地运行，无外部字体、图片、脚本或构建依赖。查询不向外部传送输入；外部链接仅用于查看来源项目。

## 文件

`index.html` 页面结构；`styles.css` 主页样式；`app.js` 主页交互；`particles.js` 粒子动效；`calculators.js` / `calculators.css` 计算弹窗；`efficiency-data.js` 能效数据与来源记录，`efficiency-query.js` 查询引擎，`efficiency.js` 查询界面；`serve.mjs` 仅监听本机的预览服务（只允许访问页面所需资源，不暴露测试或其他文件）。

- 空间入口、部件高亮、快捷搜索、收藏、最近使用、动画控制与待开发功能浮层。
- 桌面及手机布局。
